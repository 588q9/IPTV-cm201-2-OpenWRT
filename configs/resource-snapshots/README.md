# 公开签名索引快照

本目录只保存 `resources.lock.json` 中的五份官方 OpenWrt `packages.adb` 原始字节，不包含设备 `/lib/apk/db/installed`、配置、订阅或设备备份。

来源 URL、feed、版本日期、长度和 SHA256 见 [provenance.json](provenance.json)。`base-20261011` 用于现有锁定无线包；`base` 用于新增网络扩展依赖。两份历史索引对应同一上游 URL 的不同快照，不能互相替换；删除旧快照会改变无线包内容身份。

`prepare` 优先校验并复制这些快照到原缓存路径，仍以资源锁的完整摘要为准。任何缺失或不符均失败，不通过联网下载另一份当前索引来掩盖错误。签名字段未修改，设备端 APK 仍按官方信任密钥验签。本次保存前核对了字节长度和锁定 SHA256，不将此描述为一次新的主机端签名验收。

快照只解决索引的不可变取得；其他历史 APK、源码和工具仍需要上游提供锁定字节，或通过可信的 `prepare --import-dir` 导入。原厂资料继续由使用者自行保存，不在本目录分发。
