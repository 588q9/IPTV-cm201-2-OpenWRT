# 项目架构与功能索引

统一设备操作入口为 [tools/project.py](../../tools/project.py)。底层构造和校验可以单独运行公共测试，不会因为导入模块就连接设备。

| 职责 | 源码 | 验证 |
| --- | --- | --- |
| 固定资源、缓存和公开索引 | `resources.py`、`resources.lock.json`、`configs/resource-snapshots/` | `test_public_resources.py`、`test_public_remote_assets.py` |
| 原厂档案、几何与镜像格式 | `profile.py`、`hardware.py`、`layout.py`、`images.py` | profile/hardware/layout/image 相关公共测试 |
| ELF、补丁与 ARM 编译 | `elf.py`、`patching.py`、`compiler.py`、`legacy_firewall.py` | compiler/curl_sources 公共测试、opt-in compiler integration |
| 根系统组合和默认配置 | `rootfs.py`、`runtime.py`、`template_files.py` | build/runtime/templates/archive 公共测试 |
| 产物校验和安装包 | `artifacts.py`、`install_bundle.py` | build/installer/install_guards 公共测试 |
| RAM 构建编排 | `build.py`、`device/build-job` | build 公共测试；完整构建需本机原厂输入和设备 |
| RAM 启动、验收凭据、正式安装 | `ram.py`、`acceptance.py`、`installer.py` | ram/installer/CLI/guards 公共测试；设备验收单独记录 |
| 串口/SSH、私密作业 | `serial_link.py`、`ssh_link.py`、`device_jobs.py` | serial/device_jobs/update 公共测试 |
| 增量包信任和撤销 | `remote_update.py`、`update_policy.py`、`device/update-policy.json`、`device/network-update.uc` | remote_update 公共测试、共享政策和安装/撤销 Node fixtures |
| 凭据保护 | `credentials.py` | 合成凭据的实际 shell/子进程参数及输出测试 |
| 公开源码检查 | `publication.py` | publication 公共测试、CI 与发行前扫描 |

上述 Python 文件位于 `tools/cm2012/`。构建、安装和 RAM 编排调用下层 rootfs/artifacts/验收能力；下层不反向导入这些编排器。部分旧模块名保留单向再导出，使已有调用继续使用同一份实现。

## 功能控制面

| 功能 | 配置与实现 | 管理与说明 |
| --- | --- | --- |
| AP/STA、网口角色、静态路由 | `configs/templates/cm2012-*`，无线/网络 lib 与 journal | LuCI CM201-2 页面；[网口与路由](网口切换与静态路由.md) |
| Cloudflare DDNS | 标准 `ddns` UCI 与官方 DDNS/LuCI 包，`credentials.py` 对锁定版本作定点凭据保护 | 官方 DDNS 页面；服务默认停用，Token 设备本地输入 |
| Tailscale | `tailscale.py` 和 `cm2012-tailscale*` 模板 | 受限 RPC/LuCI，默认停用；[实施与启用](CM2012网络扩展实施与启用.md) |
| Mihomo/MetaCubeXD | `proxy.py`、`configs/remote-proxy/`、锁定程序和静态面板 | lib 定义策略、service 管理事务、native 处理设备 I/O；默认停用 |
| 生命周期协调 | `remote.py`、`cm2012-remote` | 调用各服务 suspend/reconcile，保留业务独立性 |

`configuration()` 唯一负责默认 UCI；`runtime_files()` 负责程序、UI、ACL 和链接。功能之间出现目标文件冲突时构建失败，避免用字典覆盖隐藏归属。显式 rootfs overlay 覆盖官方程序仍按原有流程处理。

历史 `tools/network-assessment/` 是独立评估归档，部分脚本导入即有设备副作用，不能作为正式测试或批量导入；详见该目录 README。

## 兼容与验收边界

CLI、UCI 包名、RPC 方法和设备文件路径保持；更新包 format 1 保留。旧包内的 updater 不再被执行，主机验证完整成员并注入本机可信版本。固件内部原有 mode/UID/GID 保留，0700/0600 仅保护私密外层作业和敏感数据。

HTTPS 管理策略暂缓。实际设备升级、登录授权、真实业务、重启与长期观察不由纯测试替代；历史记录保持原产物归属。

## 节点 DNS 恢复

DNS 专用 fallback 策略归 proxy-lib；失效采样、限频恢复和公开状态归 proxy-service；固定回环 API 和真实 DNS 检查归 native/proxy_api.h；界面仅显示脱敏状态。详见 [节点 DNS 缓存防复发](节点DNS缓存防复发-20261102.md)。
