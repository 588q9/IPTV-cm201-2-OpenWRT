## 验收边界

电脑物理网络没有断开：主机 build Python 进程拒绝联网，盒子 APK 使用 --no-network、--scripts=no 与 --commit-hooks=no。Zig 从锁定本地源码编译。不能将这种控制写成电脑物理断网测试。

当前实机物理容量为 8GiB；4/16GiB 只有合成布局测试。首次从原厂 Android 控制台重启及自动识别回到 Android 没有在本轮实测，当前起点为已安装的内部 OpenWrt。原生传输有实际双向 CRC/SHA 和模拟故障覆盖，没有真实拔线注入。没有执行新产物 NAND 刷写、断电容错或完整 Android 恢复；CI 配置已提供，GitHub 上的运行由上传后触发。

bootstrap 初次传输因原厂切速时序中断，恢复引导控制台后完成加载；首次自动激活控制台亦超时，人工回车确认系统可用后补回归修复。补充切速等待及累计激活提示、一秒间隔回车重试后，从头重跑自动 bootstrap 成功，没有人工干预；初次恢复操作仍保留为问题与修正记录。旧内核出现 devpts 选项日志，实际 /dev/pts 已挂载、串口可用；同时观察到 sysntpd 的 ujail 在 initramfs 根 pivot_root 返回 EINVAL 并重试，RAM NTP/jail 未通过；更多旧内核接口仍须按实际用途验证。

缓存、原厂输入、生成系统、密码及串口原始日志全部保留在忽略目录，不随公开记录提交。

### userdata 重建与内部复核

显式 install 通过持久分区表及保留 boot 核对，启动安装 RAM；安装包首次传输受原厂日志干扰，在格式化前中止。修复主机传输保护后留在安装 RAM，重新核对相同几何/分区/保留 boot，采用同一 C 安装包及公开阶段脚本继续。只格式化 mtd8，创建 UBI rootfs、解包后逐文件 SHA256 全部通过，随后真实从内部 NAND 启动；没有调用核心区刷写阶段。mtd0–7 完整摘要与安装前、只读 RAM 基线一致。

实际内部根为 ubi0:rootfs / ubifs rw。有线启用/关闭恢复、DHCP 续租请求、单 eth0 默认路由、DNS、公网收发通过；无线上联也用新提供的凭据完成 WPA2、DHCP、单 wlan0 默认路由/DNS、公网和 STA/AP 信道 149，通过后手动返回有线。安装过程中上游热点离开扫描结果，重新开启后连接成功；缺少上游时自动回滚，有线和热点恢复，不把不可见上游记为错误密码通过。

内部配置备份包含 cm2012，真实每分钟 cron 任务执行并恢复原空配置。再次重启后配置、SSH 主机私钥、HTTPS 密钥/证书 SHA256 均持久化；dnsmasq、ntpd、hostapd、supplicant、uhttpd、dropbear 各一个，wpad 不运行。procd 重启交接允许旧 dnsmasq 最多 5 秒退出，稳定态没有重复实例。实际 LuCI getFeatures 返回 firewall=true、firewall4=false。重启后再次通过 SSH PTY、HTTPS 登录页、匿名 RPC 拒绝和只读写入拒绝；主机公钥由串口核对，临时验收公钥经内容摘要匹配后已移除，测试只读 RPC 会话也已销毁。
