## 验收边界

电脑物理网络没有断开：主机 build Python 进程拒绝联网，盒子 APK 使用 --no-network、--scripts=no 与 --commit-hooks=no。Zig 从锁定本地源码编译。不能将这种控制写成电脑物理断网测试。

当前实机物理容量为 8GiB；4/16GiB 只有合成布局测试。首次从原厂 Android 控制台重启及自动识别回到 Android 没有在本轮实测，当前起点为已安装的内部 OpenWrt。原生传输有实际双向 CRC/SHA 和模拟故障覆盖，没有真实拔线注入。没有执行新产物 NAND 刷写、断电容错或完整 Android 恢复；CI 配置已提供，GitHub 上的运行由上传后触发。

bootstrap 初次传输因原厂切速时序中断，恢复引导控制台后完成加载；首次自动激活控制台亦超时，人工回车确认系统可用后补回归修复。补充切速等待及累计激活提示、一秒间隔回车重试后，从头重跑自动 bootstrap 成功，没有人工干预；初次恢复操作仍保留为问题与修正记录。旧内核出现 devpts 选项日志，实际 /dev/pts 已挂载、串口可用；同时观察到 sysntpd 的 ujail 在 initramfs 根 pivot_root 返回 EINVAL 并重试，RAM NTP/jail 未通过；更多旧内核接口仍须按实际用途验证。

缓存、原厂输入、生成系统、密码及串口原始日志全部保留在忽略目录，不随公开记录提交。
